# 04 — Running on Data

## The binary

```
Examples/Monocular-Inertial/mono_inertial_euroc  <vocab>  <settings.yaml>  <sequence_dir>  <times_file>  [output_prefix]
```

| Argument | Value |
|---|---|
| `vocab` | `Vocabulary/ORBvoc.txt` |
| `settings.yaml` | camera + IMU calibration (see below) |
| `sequence_dir` | the EuRoC dataset dir (contains `mav0/`) |
| `times_file` | usually `<sequence_dir>/cam0_times.txt` |
| `output_prefix` | tag for the output files, e.g. `run1` → `f_run1.txt` |

**Settings files:** stock EuRoC uses `Examples/Monocular-Inertial/EuRoC.yaml`; NORA/historical flights use per-flight configs under the eval workspace (`configs/hist/<key>.yaml`, generated by the converter).

## Behaviour is controlled by environment variables

All default to stock. Full list: [doc 08](08-environment-variable-reference.md).

**Recommended "campaign" env** (deterministic, headless, dim-footage equalization):

```bash
export ORB_DETERMINISTIC=1      # reproducible, single-threaded
export OMP_NUM_THREADS=1
export ORB_CLAHE=3.0            # contrast equalization (load-bearing on aerial footage)
export ORB_TSJUMP_S=3.0         # don't reset the map across multi-second camera drops
```

**Altitude + heading fusion** (needs the matching sidecars):

```bash
export ORB_BARO_CSV=<dataset>/ref_baro.csv   ORB_BARO_SIGMA=0.15   ORB_BARO_GATE=6
export ORB_BARO_FRAME_SIGMA=0.5              # per-frame z pin (stabilizes fragile inits)
export ORB_MAG_CSV=<dataset>/ref_mag.csv     ORB_MAG_SIGMA_DEG=10
```

**Efficient batch runs:**

```bash
export ORB_DIVERGE_VMAX=30  ORB_DIVERGE_COUNT=4   # stop early if it blows up
export ORB_PREFETCH=all  ORB_NO_PACE=1            # off-thread extraction, run flat-out
```

## Runner scripts (in the eval workspace)

| Script | Usage | Use for |
|---|---|---|
| `eval_fast/run_flight.sh` | `run_flight.sh <flight> <nf> <out_dir> [times]` | one headless flight + RSS/CPU sampling |
| `eval/ic_tune/run_viewer.sh` | `[NF=n] run_viewer.sh <flight_substr> [recipe.env]` | one flight with the Pangolin/GPS overlay |
| `eval/det_queue.sh` | `det_queue.sh <queue.txt> <batch> [parallel]` | many deterministic flights in parallel |

`ORB_DETERMINISTIC=1` makes SLAM single-threaded, so several **processes** can run in parallel safely (no in-process g2o race).

## Output files

| File | Contents |
|---|---|
| `f_<prefix>.txt` | full per-frame trajectory (TUM: `t tx ty tz qx qy qz qw`) — the file scorers read |
| `kf_<prefix>.txt` | keyframe-only trajectory |
| `frame_stats.csv` | per-frame stats (if `ORB_STATS_CSV` set) — detections, matches, thresholds |
| `run.log` | stdout, incl. the `RUN SUMMARY` line (coverage, divergence flag) |

## Quick recipes (from tuning)

```bash
# 542-class (low, flat): strong baro
ORB_CLAHE=3.0 ORB_BARO_CSV=…/ref_baro.csv ORB_BARO_SIGMA=0.075 ORB_BARO_GATE=6   # nFeatures 5000

# 538-class (high, relief): baro + per-frame z pin for init stability
ORB_CLAHE=3.0 ORB_BARO_CSV=…/ref_baro.csv ORB_BARO_SIGMA=0.075 ORB_BARO_FRAME_SIGMA=0.5
```
